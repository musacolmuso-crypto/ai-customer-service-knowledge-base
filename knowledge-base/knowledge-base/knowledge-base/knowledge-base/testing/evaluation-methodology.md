# AI Evaluation Methodology

## Objective

Evaluate whether the AI knowledge assistant can provide accurate, source-grounded customer-service information while recognising situations requiring clarification or escalation.

## Scoring

Each answer receives:

### 2 — Correct
The answer is accurate, complete and appropriately supported by the knowledge base.

### 1 — Partially Correct
The answer contains correct information but misses an important qualification or clarification.

### 0 — Incorrect
The answer is materially incorrect, unsupported or provides information that should have been escalated.

## Additional Evaluation Criteria

Each response is also evaluated for:

- Correct source identification
- Appropriate clarification
- Appropriate escalation
- Hallucination
- Completeness
- Response clarity

## AI Behaviour Principle

The assistant should not be rewarded simply for producing an answer.

In ambiguous situations, asking the correct clarification question may represent better performance than attempting to answer immediately.
